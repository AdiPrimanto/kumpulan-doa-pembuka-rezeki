# kumpulan-doa-pembuka-rezeki

Website kumpulan surah, ayat, doa, dan dzikir pembuka rezeki: tulisan Arab, latin, arti, dan murottal per ayat.

- Teks, terjemahan (Kemenag RI), dan audio Al-Qur'an dari [equran.id](https://equran.id)
- Wirid harian, penghitung tasbih, dan link per doa (`#id-doa`) — data tersimpan di browser

## Menjalankan

Situs statis tanpa build:

```
python3 -m http.server 8765
```

Lalu buka http://localhost:8765
